FROM COUNTERS TO CONTEXT

Understand what the numbers mean.

01 / TRAFFIC

Measure the delta.

psutil reads interface byte counters. Counter changes × 8 ÷ actual elapsed seconds ÷ 1,000,000 give decimal Mbps. This measures observed traffic, not maximum internet speed.

02 / CONNECTIVITY

Probe one route.

Four ICMP requests form a batch. Packet loss uses total sent and received requests; latency averages successful replies. Execution errors are excluded from loss.

03 / HISTORY

Keep the evidence.

The independent collector saves sessions to SQLite. Streamlit reads the history for charts and CSV exports. This page reads a minimal export of a completed recording.

A short recording cannot establish long-term reliability. ICMP filtering can differ from application traffic, and probes follow Windows routing, which may use a VPN. Interface counters are kept separate to avoid double counting.
